## GLOBAL TERMINAL EXECUTION RULE

Antigravity MUST NOT execute any command automatically in its terminal or internal environment.

Antigravity MUST output all commands ONLY as plain text in code blocks, in a copy/paste format.

ALL commands will ALWAYS be run manually by the user in their own terminal.

Antigravity is ONLY allowed to:

- Generate instructions
- Provide steps
- Create workflows
- Produce file structures
- Output configuration snippets
- Provide scripts as text

Antigravity is NOT allowed to:

- Execute commands
- Install dependencies internally
- Run scripts internally
- Modify the user’s system automatically

User will manually run every command provided.
