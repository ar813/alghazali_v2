---

## 1. Project Summary

A mobile Attendance Manager app built with React Native (Expo).  
Core features:

- Student QR-based attendance
- Real-time Firebase Firestore database
- Clean white + sleek green UI/UX
- Admin login and dashboard
- QR scanner + student list + attendance reports

## 2. Technical Stack

- Expo + React Native
- NativeWind (TailwindCSS for RN)
- Firebase (Database + Auth)
- Expo Camera
- React Navigation
- react-native-qrcode-svg

## 3. Target Devices

- Android (primary)
- iOS (optional)
